> Here's how I orchestrate automated intelligence:

```
  +------------------+         +--------------------+         +-------------------+
  |   Task Prompt    | ------> | Lead AI Agent (A)  | ------> | Debate Engine (B) |
  +------------------+         +--------------------+         +-------------------+
           ^                             |                              |
           |                             v                              v
  +------------------+         +--------------------+         +-------------------+
  | Standard Output  | <------ | Execution Sandbox  | <------ | Code Verifier (C) |
  +------------------+         +--------------------+         +-------------------+
```

### Setup Philosophy
- **Self-Healing Code Loops:** Agents run linting and unit tests continuously inside a secure container sandbox.
- **Strategic Consensus:** Dual-agent architectures where one writes test suites and the other tries to pass them, mimicking human TDD.
- **Hardware Integration:** Running local lightweight inference pipelines utilizing pruned quantizations on consumer hardware.

### 🚧 RoadZen — AI-Powered Road Safety Engine
<p align="left">
  <a href="https://github.com/hariharasudhan-29507/ROADZEN" target="_blank">
    <img src="https://img.shields.io/badge/ROADZEN-View_Repo_&_Code-4F624C?style=for-the-badge&logo=github&logoColor=white&v=1.0.0" alt="ROADZEN" />
  </a>
</p>

<details>
<summary><b>🔍 Click here to see RoadZen Architecture, Features and Tech Details</b></summary>
<br />

- **The Vision:** Real-time accident severity classifier powered by FastAPI.
- **AI/ML Core:** Utilizes an **XGBoost Classifier** to ingest traffic, environmental, and regional datasets, outputting exact risk scores.
- **Explainable AI:** Plugs in **SHAP** (SHapley Additive exPlanations) to explain feature importance directly to the end user.
- **Data Visualizations:** Interactive geographical heatmaps alongside a 6-chart robust dashboard to map out regional danger spots.
- **Bonus Capabilities:** Safe-route calculation chatbot and automated notification dispatch for emergency units.
</details>
